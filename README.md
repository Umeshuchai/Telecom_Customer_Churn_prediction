# Customer Churn Prediction

My first machine learning project, built while learning the fundamentals of ML with Python and scikit-learn.

## Objective

Explore customer data and build machine learning models to predict whether a telecom customer is likely to churn.

## What I'm Learning

* Data preprocessing and exploratory data analysis (EDA)
* Feature encoding and scaling
* Feature selection using mutual information
* Correlation analysis
* Training and comparing classification models
* Evaluating models using accuracy and F1-score

## Models

* Logistic Regression
* Random Forest
* Support Vector Machine (SVM)

## Tools & Libraries

* Python
* Pandas
* NumPy
* Matplotlib & Seaborn
* Scikit-learn
* Jupyter Notebook

## Project Status

**Learning / In progress**

This is an early implementation created for practice. The preprocessing, feature selection, model evaluation, and overall pipeline may change as I learn more machine learning concepts.

Planned improvements include experimenting with XGBoost, hyperparameter tuning, cross-validation, and model explainability.

## How to Run

1. Clone this repository.
2. Install the required dependencies.
3. Open `customer_churn_prediction.ipynb` in Jupyter Notebook or VS Code.
4. Run the notebook cells in order.

## Note

This project is for educational purposes. Model results are preliminary and should not be treated as production-ready predictions.
